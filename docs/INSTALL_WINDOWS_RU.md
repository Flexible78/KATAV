# KATAV - установка на Windows для совсем новичков

Эта инструкция рассчитана на **полное отсутствие опыта**: без Python, без командной строки, без Git.
Просто выполняйте шаги по порядку. Всего нужно 15-25 минут.

English version: **[INSTALL_WINDOWS.md](INSTALL_WINDOWS.md)**

Если что-то не получилось - смотрите [Проблемы и решения](#проблемы-и-решения) в конце.

## Что получится в итоге

- KATAV установлен в папку, например `C:\KATAV`
- В браузере открывается страница, куда вы кидаете аудио или видео и получаете текст
- Всё работает на вашем компьютере: для распознавания **не нужен интернет и не нужны API-ключи**

## Что нужно заранее

- Windows 10 или 11, 64-bit
- Около 10 ГБ свободного места на диске
- Желательно видеокарта NVIDIA (без неё тоже работает, только медленнее)
- Права администратора для обычного пути установки не требуются

## Шаг 1 - установить Python

1. Откройте <https://www.python.org/downloads/windows/>
2. Скачайте **Windows installer (64-bit)** для Python 3.12 или новее.
3. Запустите скачанный файл.
4. **Очень важно:** на первом экране поставьте галочку **Add python.exe to PATH** (внизу окна). Без неё дальше ничего не заработает.
5. Нажмите **Install Now**, дождитесь конца, нажмите **Close**.
6. Проверка: нажмите **Win**, напишите `powershell`, нажмите **Enter** и введите:

```powershell
python --version
```

Должно появиться что-то вроде `Python 3.12.6`. Если вместо этого ошибка - смотрите [Проблемы и решения](#проблемы-и-решения).

---

## Шаг 2 - скачать KATAV

### Вариант A - без Git (самый простой)

1. Откройте <https://github.com/Flexible78/KATAV>
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. В папке **Загрузки** нажмите на архив правой кнопкой и выберите **Извлечь всё...**
4. Переместите/переименуйте распакованную папку так, чтобы получилось `C:\KATAV`, и файл `main.py` лежал **прямо внутри неё**.

Правильно:

```
C:\KATAV\main.py
```

Неправильно (лишний уровень - поднимите внутреннюю папку выше):

```
C:\KATAV\KATAV-main\main.py
```

### Вариант B - через Git

```powershell
cd C:\
git clone https://github.com/Flexible78/KATAV.git
```

## Шаг 3 - скачать движок распознавания (Faster-Whisper-XXL)

Сам движок в KATAV не входит, его нужно скачать один раз отдельно.

1. Откройте <https://github.com/Purfview/whisper-faster-XXL>
2. Перейдите в раздел **Releases** и скачайте архив для Windows.
3. Распакуйте его так, чтобы папка лежала **рядом** с папкой KATAV:

```
C:\
|-- KATAV\
|   |-- main.py
|-- Faster-Whisper-XXL\
    |-- faster-whisper-xxl.exe
```

KATAV сам ищет `faster-whisper-xxl.exe` в своей папке и в папке уровнем выше, поэтому при такой раскладке настраивать ничего не нужно.
Другие способы указать путь описаны в [SETUP.md](SETUP.md).

---

## Шаг 4 - открыть терминал внутри папки KATAV

1. Откройте **Проводник** и зайдите в `C:\KATAV`.
2. Нажмите один раз на **адресную строку** сверху (там, где написан путь).
3. Напишите `powershell` и нажмите **Enter**.

Откроется окно терминала, и первая строка уже будет заканчиваться на `C:\KATAV`. Все команды ниже вводятся в этом окне (вставка - правая кнопка мыши).

---

## Шаг 5 - установить зависимости

Введите три команды по очереди, после каждой нажимая **Enter**:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

- Первая команда создаёт отдельное окружение Python внутри проекта (папка `.venv`).
- После второй команды строка начинается с `(.venv)` - это правильно.
- Третья команда качает библиотеки, это может занять несколько минут. Жёлтые предупреждения - норма, важны только красные строки `ERROR`.

Если вторая команда пишет, что запуск скриптов запрещён, выполните один раз и повторите активацию:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

---

## Шаг 6 - запустить KATAV

```powershell
python main.py
```

Дождитесь строки вида:

```
Running on local URL:  http://127.0.0.1:7861
```

Откройте этот адрес в браузере (обычно он открывается сам). Эта страница и есть KATAV.

Чтобы остановить программу: нажмите **Ctrl + C** в окне терминала или кнопку **EXIT** в интерфейсе.

---

## Шаг 7 - первое распознавание

1. Перетащите аудио или видео в область загрузки либо вставьте ссылку с YouTube.
2. Выберите нужные опции (субтитры, чистый текст, перевод).
3. Нажмите кнопку запуска.
4. Готовые файлы появятся в папке `Outputs` внутри `C:\KATAV`, их также можно скачать со страницы.

Распознавание работает полностью офлайн. Интернет нужен только для перевода и для скачивания видео по ссылке.

---

## Шаг 8 - как запускать в следующий раз

В дальнейшем достаточно трёх строк:

```powershell
cd C:\KATAV
.venv\Scripts\Activate.ps1
python main.py
```

Короткий путь: в папке `C:\KATAV` можно просто дважды щёлкнуть по файлу **`start.bat`** - он выполнит запуск за вас.

## Проблемы и решения

| Что видно на экране | Что это значит | Что делать |
| --- | --- | --- |
| `python : The term 'python' is not recognized` | Python не прописан в PATH | Переустановите Python с галочкой **Add python.exe to PATH** и откройте новый терминал |
| `... Activate.ps1 cannot be loaded because running scripts is disabled` | Политика запуска скриптов PowerShell | Выполните `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и активируйте окружение снова |
| `faster-whisper-xxl.exe was not found` | Движок из шага 3 не скачан или лежит не там | Проверьте раскладку папок в шаге 3 или задайте `$env:WHISPER_EXE = "C:\Tools\Faster-Whisper-XXL\faster-whisper-xxl.exe"` перед `python main.py` |
| `Cannot find empty port in range: 7861-7861` | KATAV уже запущен в другом окне | Закройте другое окно или выполните `$env:GRADIO_SERVER_PORT='7899'` и запустите снова |
| `pip` падает с красными ошибками | Устаревший pip | Выполните `python -m pip install --upgrade pip` и повторите `pip install -r requirements.txt` |
| Распознавание идёт очень медленно | Нет видеокарты NVIDIA, работа идёт на процессоре | Это нормально: выберите модель поменьше или используйте компьютер с GPU |
| В браузере ничего не открылось | Страница не открылась автоматически | Скопируйте адрес `http://127.0.0.1:...` из терминала в браузер вручную |
| Русский или иврит выглядят как крокозябры | Редактор не читает UTF-8 | Откройте файл в VS Code, Word или Notepad++ вместо старого Блокнота |

## Нужны ли API-ключи?

- **Для распознавания речи - нет.** Оно полностью локальное и бесплатное.
- **Для AI-перевода - да**, нужен ключ одного из провайдеров. См. [SETUP.md](SETUP.md). Ключи хранятся в вашем локальном файле `whisper_api_keys.json`, который никуда не выгружается.

## Как удалить

Удалите папку `C:\KATAV` и папку `Faster-Whisper-XXL`. В реестр Windows программа ничего не пишет.
