# KATAV - התקנה על Windows למתחילים מלאים

המדריך הזה מיועד למי שאין לו שום ניסיון: בלי Python, בלי שורת פקודה ובלי Git.
פשוט בצעו את השלבים לפי הסדר. זמן משוער: 15-25 דקות.

שפות נוספות: **[English](INSTALL_WINDOWS.md)** · **[Русский](INSTALL_WINDOWS_RU.md)**

אם משהו לא עובד - עברו ל[בעיות ופתרונות](#בעיות-ופתרונות) בסוף הדף.

## מה תקבלו בסוף

- KATAV מותקן בתיקייה, למשל `C:\KATAV`
- דף בדפדפן שאליו גוררים קובץ אודיו או וידאו ומקבלים טקסט
- הכול רץ על המחשב שלכם: לתמלול **לא צריך אינטרנט ולא צריך מפתחות API**

## מה צריך מראש

- Windows 10 או 11, גרסת 64-bit
- כ-10 ג'יגה-בייט מקום פנוי בדיסק
- מומלץ כרטיס גרפי של NVIDIA (גם בלעדיו זה עובד, רק לאט יותר)
- להתקנה בנתיב הרגיל **אין צורך** בהרשאות מנהל

## שלב 1 - התקנת Python

1. פתחו את <https://www.python.org/downloads/windows/>
2. הורידו **Windows installer (64-bit)** של Python 3.12 ומעלה.
3. הפעילו את הקובץ שהורדתם.
4. **חשוב מאוד:** במסך הראשון סמנו את התיבה **Add python.exe to PATH** (בתחתית החלון). בלעדיה שום דבר בהמשך לא יעבוד.
5. לחצו **Install Now**, המתינו לסיום ואז **Close**.
6. בדיקה: הקישו **Win**, כתבו `powershell`, הקישו **Enter** והריצו:

```powershell
python --version
```

אמורה להופיע שורה כמו `Python 3.12.6`. אם מופיעה שגיאה - ראו [בעיות ופתרונות](#בעיות-ופתרונות).

## שלב 2 - הורדת KATAV

### אפשרות א - בלי Git (הפשוטה ביותר)

1. פתחו את <https://github.com/Flexible78/KATAV>
2. לחצו על הכפתור הירוק **Code** ואחר כך על **Download ZIP**.
3. בתיקיית ההורדות לחצו קליק ימני על הארכיון ובחרו **Extract All...**
4. סדרו את התיקיות כך שיתקבל `C:\KATAV`, והקובץ `main.py` יהיה **ישירות בתוכה**.

נכון:

```
C:\KATAV\main.py
```

לא נכון (רמה אחת עמוקה מדי - העלו את התיקייה הפנימית):

```
C:\KATAV\KATAV-main\main.py
```

### אפשרות ב - עם Git

```powershell
cd C:\
git clone https://github.com/Flexible78/KATAV.git
```

## שלב 3 - הורדת מנוע הזיהוי (Faster-Whisper-XXL)

המנוע עצמו אינו חלק מ-KATAV, מורידים אותו פעם אחת בנפרד.

1. פתחו את <https://github.com/Purfview/whisper-faster-XXL>
2. עברו ל-**Releases** והורידו את הארכיון ל-Windows.
3. חלצו אותו כך שהתיקייה תשב **ליד** תיקיית KATAV:

```
C:\
|-- KATAV\
|   |-- main.py
|-- Faster-Whisper-XXL\
    |-- faster-whisper-xxl.exe
```

KATAV מחפש את `faster-whisper-xxl.exe` בתיקייה שלו ובתיקיית האם, ולכן במבנה הזה אין מה להגדיר.
דרכים נוספות להצביע על הקובץ מתועדות ב-[SETUP.md](SETUP.md).

## שלב 4 - פתיחת טרמינל בתוך תיקיית KATAV

1. פתחו את **סייר הקבצים** ועברו ל-`C:\KATAV`.
2. לחצו קליק אחד על **שורת הכתובת** למעלה (שם כתוב הנתיב).
3. כתבו `powershell` והקישו **Enter**.

נפתח חלון טרמינל, והשורה הראשונה בו מסתיימת ב-`C:\KATAV`. כל הפקודות בהמשך נכתבות בחלון הזה (הדבקה - קליק ימני).

### דרכים נוספות לפתוח טרמינל

1. הקישו **Win**, כתבו `powershell` והקישו **Enter**, ואז עברו לתיקיית הפרויקט:

   ```powershell
   cd C:\KATAV
   ```

2. הקישו **Win + X** ובחרו **Terminal** או **Windows PowerShell**.
3. בסייר הקבצים החזיקו **Shift**, לחצו קליק ימני על מקום ריק בתיקייה ובחרו **Open PowerShell window here** / **Open in Terminal**.

### PowerShell או שורת הפקודה (cmd)?

כל הפקודות במדריך נכתבו ל-**PowerShell** (הטרמינל שמוגדר כברירת מחדל ב-Windows 10/11). אם נוח לכם עם **cmd** הישן, הכול זהה חוץ מהפעלת הסביבה:

| טרמינל | פקודת הפעלה |
| --- | --- |
| PowerShell | `.venv\Scripts\Activate.ps1` |
| שורת הפקודה (cmd) | `.venv\Scripts\activate.bat` |

### איך מריצים טרמינל כמנהל (Administrator)

**ברוב המקרים אין בזה צורך** - קראו קודם את הסעיף הבא. אם בכל זאת צריך:

1. הקישו **Win** וכתבו `powershell` (או `cmd`).
2. בתוצאות החיפוש לחצו על **Run as administrator** / **הפעל כמנהל**. קיצור מקלדת: **Ctrl + Shift + Enter**.
   - דרך נוספת: **Win + X**, ואז **Terminal (Admin)** / **Windows PowerShell (Admin)**.
3. אשרו את חלונית ה-UAC של Windows בלחיצה על **Yes** / **כן**.
4. חלון מנהל נפתח תמיד ב-`C:\Windows\System32`, לכן עברו קודם לתיקיית הפרויקט:

   ```powershell
   cd C:\KATAV
   ```

5. כדי לוודא שהחלון אכן בהרשאות מנהל: בכותרת החלון מופיעה המילה **Administrator**, או שמריצים:

   ```powershell
   ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
   ```

   תשובה `True` פירושה שהחלון מורם להרשאות מנהל.

### האם בכלל צריך הרשאות מנהל?

| מצב | צריך מנהל? |
| --- | --- |
| התקנה רגילה ל-`C:\KATAV` או ל-`C:\Users\<השם שלכם>\KATAV` | **לא** |
| יצירת `.venv`, הרצת `pip install`, הרצת `python main.py` | **לא** |
| תמלול קבצים, תרגום, עבודה בדפדפן | **לא** |
| הפרויקט הונח בתוך `C:\Program Files` או בשורש דיסק המערכת | כן (מוטב להעביר את הפרויקט ל-`C:\KATAV`) |
| השגיאה `Access is denied` ביצירת `.venv` או בכתיבה ל-`Outputs` | כן, פעם אחת - או להעביר את הפרויקט לתיקיית משתמש רגילה |
| התקנת Python **לכל המשתמשים** או שינוי משתנה סביבה **מערכתי** | כן |
| פתיחת פורט בחומת האש (רק אם פותחים גישה ברשת המקומית) | כן |

> **לא מריצים את KATAV כמנהל דרך קבע.** קבצים שנוצרו בתהליך מורם עלולים להיות קשים למחיקה או לדריסה מחלון רגיל. אם כבר יצרתם `.venv` כמנהל ויש בעיות הרשאות - מחקו את התיקייה `.venv` וחזרו על שלב 5 בחלון רגיל.

## שלב 5 - התקנת הספריות

הקלידו שלוש פקודות, אחת אחרי השנייה, עם **Enter** בסוף כל אחת:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

- הפקודה הראשונה יוצרת סביבת Python נפרדת בתוך הפרויקט (תיקייה `.venv`).
- אחרי הפקודה השנייה השורה מתחילה ב-`(.venv)` - זה תקין.
- הפקודה השלישית מורידה את הספריות ויכולה לקחת כמה דקות. אזהרות בצהוב הן בסדר, חשובות רק שורות `ERROR` באדום.

אם הפקודה השנייה נחסמת בהודעה שהרצת סקריפטים אסורה, הריצו פעם אחת וחזרו על ההפעלה:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## שלב 6 - הפעלת KATAV

```powershell
python main.py
```

המתינו לשורה כמו:

```
Running on local URL:  http://127.0.0.1:7861
```

פתחו את הכתובת בדפדפן (בדרך כלל היא נפתחת לבד). הדף הזה הוא KATAV.

לעצירה: **Ctrl + C** בחלון הטרמינל, או כפתור **EXIT** בממשק.

## שלב 7 - התמלול הראשון

1. גררו קובץ אודיו או וידאו לאזור ההעלאה, או הדביקו קישור מיוטיוב.
2. בחרו את האפשרויות הדרושות (כתוביות, טקסט נקי, תרגום).
3. לחצו על כפתור ההפעלה.
4. בסיום הקבצים מופיעים בתיקייה `Outputs` שבתוך `C:\KATAV`, ואפשר גם להוריד אותם מהדף.

התמלול עובד לגמרי בלי אינטרנט. אינטרנט נחוץ רק לתרגום ולהורדת סרטונים מקישור.

## שלב 8 - איך מפעילים בפעם הבאה

בכל פעם הבאה מספיקות שלוש שורות:

```powershell
cd C:\KATAV
.venv\Scripts\Activate.ps1
python main.py
```

קיצור דרך: בתיקייה `C:\KATAV` אפשר גם ללחוץ לחיצה כפולה על **`start.bat`**, שמבצע את ההפעלה במקומכם.

## בעיות ופתרונות

| מה מופיע על המסך | מה זה אומר | מה לעשות |
| --- | --- | --- |
| `python : The term 'python' is not recognized` | Python לא נוסף ל-PATH | התקינו מחדש עם הסימון **Add python.exe to PATH** ופתחו טרמינל חדש |
| `... Activate.ps1 cannot be loaded because running scripts is disabled` | מדיניות הרצת סקריפטים ב-PowerShell | הריצו `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` והפעילו את הסביבה שוב |
| `faster-whisper-xxl.exe was not found` | המנוע משלב 3 חסר או נמצא במקום הלא נכון | בדקו את מבנה התיקיות בשלב 3, או הגדירו את `WHISPER_EXE` לנתיב המלא לפני `python main.py` |
| `Cannot find empty port in range: 7861-7861` | KATAV כבר רץ בחלון אחר | סגרו את החלון האחר, או הגדירו `GRADIO_SERVER_PORT` לפורט אחר והפעילו מחדש |
| `pip` נכשל עם שגיאות אדומות | pip מיושן | הריצו `python -m pip install --upgrade pip` וחזרו על `pip install -r requirements.txt` |
| התמלול איטי מאוד | אין כרטיס NVIDIA, העבודה על המעבד | זה מצב תקין: בחרו מודל קטן יותר או השתמשו במחשב עם GPU |
| הדפדפן לא נפתח | הדף לא נפתח אוטומטית | העתיקו את הכתובת `http://127.0.0.1:...` מהטרמינל לדפדפן ידנית |
| עברית או רוסית נראות כג'יבריש | העורך לא קורא UTF-8 | פתחו את הקובץ ב-VS Code, ב-Word או ב-Notepad++ במקום ב-Notepad הישן |
| `Access is denied` ביצירת `.venv` או בכתיבת קבצים | התיקייה מוגנת (למשל בתוך `Program Files`) | העבירו את הפרויקט ל-`C:\KATAV`, או פתחו טרמינל כמנהל (ראו שלב 4) |
| `.venv\Scripts\activate.bat` לא מזוהה ב-PowerShell | פקודת הפעלה לא מתאימה לטרמינל | ב-PowerShell השתמשו ב-`.venv\Scripts\Activate.ps1`; `activate.bat` הוא ל-`cmd` בלבד |

## האם צריך מפתחות API?

- **לתמלול (דיבור לטקסט) - לא.** הוא מקומי לחלוטין וללא עלות.
- **לתרגום AI - כן**, מפתח של אחד הספקים. ראו [SETUP.md](SETUP.md). המפתחות נשמרים בקובץ מקומי `whisper_api_keys.json` שאינו נשלח לשום מקום.

מחקו את התיקייה `C:\KATAV` ואת התיקייה `Faster-Whisper-XXL`. התוכנה אינה כותבת דבר לרישום (Registry) של Windows.
